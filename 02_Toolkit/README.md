# 02_Toolkit — Cyber Essentials Readiness Toolkit

This toolkit translates Cyber Essentials requirements into practical SME-ready documents and workflows.

## How an SME uses this toolkit
1. **Complete the initial questionnaire**
2. **Generate a gap assessment**
3. **Prioritise actions (quick wins first)**
4. **Collect evidence using the evidence table**
5. **Maintain compliance via monitoring & review**

## Toolkit Components
- **Initial_Assessment_Questionnaire**  
  Captures current security posture and readiness baseline.

- **Gap_Assessment_Report**  
  Documents gaps, risk, impact, remediation actions, and owner/date tracking.

- **Device_and_Access_Control**  
  Practical controls for inventory, least privilege, onboarding/offboarding.

- **Firewall_and_MFA_Guidance**  
  Minimum firewall rules, secure remote access, MFA rollout guidance.

- **Patch_Management_Policy**  
  Patch schedules, update governance, exception handling, evidence requirements.

- **Monitoring_and_Review_Checklist**  
  Operational checklist for maintaining CE compliance after initial readiness.

- **Evidence Table** (stored in 01_Documentation)  
  Maps each CE control to specific proof artefacts.

## Output
At the end, the SME has:
- Completed assessment
- Gap report with priorities
- Evidence pack structure ready for Cyber Essentials assessment
