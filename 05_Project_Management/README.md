1. PURPOSE

This Password Policy establishes minimum requirements for creating, protecting, and managing passwords used to access [Company Name] information systems and data. This policy supports compliance with the Cyber Essentials framework and protects against unauthorized access.

2. SCOPE

This policy applies to:
- All employees, contractors, and third parties
- All user accounts including privileged/administrator accounts
- All systems, applications, and devices owned or managed by [Company Name]

3. POLICY STATEMENTS

3.1 Password Complexity Requirements

All passwords MUST meet the following minimum requirements:
- Minimum length: 12 characters (16+ recommended for admin accounts)
- Must contain a mix of:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@£$%^&*)
- Must NOT contain:
  - Dictionary words
  - Personal information (names, birthdates)
  - Company name
  - Sequential characters (123, abc)
  - Repeated characters (aaa, 111)

3.2 Password Protection

Users MUST:
- Keep passwords confidential - never share with anyone
- Never write passwords down or store in plain text
- Use a password manager for storing multiple passwords
- Never send passwords via email or instant messaging
- Use different passwords for different systems

Users MUST NOT:
- Share passwords with colleagues or IT support
- Use the same password across multiple systems
- Store passwords in browsers without master password protection
- Reuse old passwords

3.3 Password Changes

- Users must change passwords immediately if compromise is suspected
- Passwords must be changed if requested by IT security team
- New passwords must be significantly different from previous passwords
- Default passwords must be changed immediately upon first login

3.4 Account Lockout

- Accounts will lock after 5 failed login attempts
- Locked accounts will remain locked for 15 minutes OR until unlocked by IT support
- Repeated lockouts may trigger security investigation

3.5 Multi-Factor Authentication (MFA)

- MFA is MANDATORY for:
  - All administrator/privileged accounts
  - Remote access (VPN, cloud services)
  - Email access from external networks
  - Financial systems
- MFA is RECOMMENDED for all user accounts

3.6 Password Managers

- [Company Name] authorizes the use of password managers
- Recommended solutions: [List approved password managers]
- Password managers MUST be protected with a strong master password
- Master passwords MUST meet or exceed standard complexity requirements

4. RESPONSIBILITIES

4.1 All Users
- Comply with all password requirements
- Report suspected password compromise immediately
- Attend security awareness training

4.2 IT Department / System Administrators
- Enforce password policy through technical controls
- Monitor for password-related security incidents
- Provide password reset services securely
- Maintain password policy enforcement systems

4.3 Management
- Ensure policy compliance within their teams
- Support disciplinary action for policy violations
- Allocate resources for password management tools

5. ENFORCEMENT

Violations of this policy may result in:
- Warning and mandatory security awareness training
- Temporary suspension of system access
- Disciplinary action up to and including termination
- Legal action if malicious intent is proven

6. RELATED DOCUMENTS

- Acceptable Use Policy
- Information Security Policy
- Remote Access Policy
- Incident Response Procedure

7. POLICY REVIEW

This policy will be reviewed annually or following:
- Significant security incidents
- Changes to regulatory requirements
- Changes to business operations
- Cyber Essentials re-certification

8. APPROVAL

This policy has been approved by:

_______________________________          Date: ___________
[Name], [Title]

9. REVISION HISTORY

Version | Date | Author | Changes
1.0 | [Date] | [Name] | Initial policy creation
