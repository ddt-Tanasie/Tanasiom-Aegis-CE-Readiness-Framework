## What will be included
- Testing plan (functional + usability + basic security checks)
- Test cases and results
- Screenshots evidence
- User feedback notes (2–5 participants is enough)
- Evaluation write-up:
  - what worked well
  - limitations
  - improvements / future work

## Minimum Evaluation Targets
- Demonstrate correct scoring and output
- Demonstrate that an SME user can follow the toolkit workflow
- Identify improvements from feedback
