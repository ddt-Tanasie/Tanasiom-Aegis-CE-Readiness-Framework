# Overview

This folder contains the testing, validation, and evaluation materials used to demonstrate the effectiveness, usability, and practical applicability of the Tanasiom Aegis Cyber Essentials Readiness Framework.

The purpose of evaluation is to determine whether the framework successfully supports SMEs in assessing Cyber Essentials readiness, identifying compliance gaps, prioritising remediation activities, and collecting evidence required for certification preparation.

Evaluation activities provide evidence that the proposed solution functions as intended and delivers measurable value to organisations with limited cybersecurity expertise.

---

# Purpose

The evaluation phase aims to:

* Verify that toolkit components function correctly.
* Assess usability from an SME perspective.
* Validate readiness assessment outputs.
* Confirm gap assessment accuracy.
* Evaluate evidence collection processes.
* Identify strengths, weaknesses, and limitations.
* Generate recommendations for future improvement.

The evaluation supports the academic requirement to critically assess the effectiveness of the proposed solution.

# Evaluation Methodology

The framework should be evaluated using three complementary approaches.

---

## 1. Functional Testing

Tests whether toolkit components operate correctly.

### Objectives

Verify:

* Assessment forms function correctly.
* Readiness scoring calculations are accurate.
* Gap reports are generated correctly.
* Evidence requirements are mapped appropriately.
* Templates support intended workflows.

### Expected Outcome

The toolkit produces accurate and repeatable outputs.

---

## 2. Usability Testing

Tests whether intended users can successfully use the framework.

### Objectives

Verify:

* Instructions are understandable.
* Documents are easy to complete.
* Assessment workflow is logical.
* Required evidence can be identified.
* Outputs are useful for decision making.

### Expected Outcome

SME users can complete the readiness process with minimal external assistance.

---

## 3. Basic Security Validation

Tests whether the framework aligns with Cyber Essentials requirements.

### Objectives

Verify:

* Controls are mapped correctly.
* Evidence requirements are appropriate.
* Assessment questions reflect Cyber Essentials expectations.
* Recommendations support compliance objectives.

### Expected Outcome

Framework outputs align with Cyber Essentials guidance and recognised security practices.

The following targets represent the minimum evaluation criteria for project success.

### Readiness Assessment

Demonstrate that:

* Assessment questions function correctly.
* Readiness scoring is calculated accurately.
* Findings are clearly presented.

---

### Gap Assessment

Demonstrate that:

### Workflow Validation

Demonstrate that an SME user can:

1. Complete the readiness questionnaire.
2. Identify compliance gaps.
3. Prioritise remediation activities.
4. Collect supporting evidence.
5. Prepare for Cyber Essentials assessment.

---

### Feedback and Improvement

Demonstrate that:

* Feedback was collected.
* Findings were analysed.
* Improvements were identified.
* Future development opportunities were documented.

* Limited participant numbers.
* Simulated rather than live organisational environments.
* Time restrictions.
* Resource availability.

These limitations should be acknowledged within the final report.
